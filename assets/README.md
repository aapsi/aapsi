# Profile assets

The bespoke welcome banners have been removed. The profile uses community-sourced elements.

## Pixel-art gaming room

The user selected this existing animation from [Cool GIFs for GitHub](https://github.com/Anmol-Baranwal/Cool-GIFs-For-GitHub), where it is listed as “Mario”.

## Other elements

- Contribution arcade: existing output from [abozanona/pacman-contribution-graph](https://github.com/abozanona/pacman-contribution-graph).
- Technology icons: [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons).

## README widgets

- `focus-typing-*.svg`: generated by [DenverCoder1/readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg), with profile-specific interest lines; the name remains native static text. Color variants improve light/dark contrast, and `focus-static-*.svg` provides reduced-motion alternatives.
- `languages.svg` and `toolkit.svg`: generated by [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons), using `go,rust,ts,js,py,solidity` for languages and `react,nodejs,git` for the toolkit.
- `cards/`: generated by [vn7n24fzkq/github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards), username `aapsi`, theme `tokyonight`. Public activity, not private work or skills rankings. The refresh workflow retains the last successful files if the service fails.

The two `pacman-*.svg` files are unchanged cached copies of the existing output-branch animations, refreshed alongside the cards to keep all visual assets available from this repository. The existing generation workflow remains unchanged.

- `icons/`: [Lucide](https://github.com/lucide-icons/lucide) icons, wrapped in colored tiles to distinguish profile topics. License retained in `icons/LICENSE`.
- `badges/`: contact badges generated by [Shields.io](https://shields.io/).

## Graphic profile cards

`panels/` contains the profile expertise, curiosity, and writing cards, composed as SVG with Lucide icons and outlined [Space Grotesk](https://github.com/floriankarsten/space-grotesk) lettering. Space Grotesk is covered by `OFL-SpaceGrotesk.txt`. Icons retain the license in `icons/LICENSE`. Cards use image alternative text for their complete meaning and stack individually on mobile.

The current-work panels describe distributed systems and DePIN at Bloxtel. Company context (private 5G, onchain identity, and tokenized infrastructure) is based on [Bloxtel’s public website](https://bloxtel.com/). All informational images use picture wrappers to prevent GitHub automatic image redirects.

## Personalized room

The displayed `aapsi-pixel-room.gif` adapts the user’s public GitHub avatar into the original gaming-room character. Two generated appearance poses face the monitor and turn with the original drinking action. The original hand and drink animation is preserved; no separate arm rig is used. The room and its animation remain credited above.

The pose sources and full built-in generation prompts are documented in [aapsi-pixel-room.prompt.md](./aapsi-pixel-room.prompt.md). `aapsi-pixel-room-still.png` is the reduced-motion fallback. The original `pixel-room.gif` remains the animation source.

- `application-toolkit.svg`: Skill Icons (`react,nextjs,tailwind,nodejs,express`), cached locally. Toolkit entries reflect project manifests and existing profile tooling; no private employer implementation details are included.
